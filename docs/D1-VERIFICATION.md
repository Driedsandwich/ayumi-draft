# D1 画面改修・検証結果

あゆみの下書き / 2026年11月6日

## 変更点

- `.npmrc` を復元し、既存の lockfile で依存を導入。新しい依存は追加していません。
- 結果画面を先に整え、左に期間の帯・中央に期間表と本人の言葉・右に確認事項を配置しました。期間表は生活・仕事・受診先を分け、印刷では治療経過と原文全文も残します。
- 初回画面は作品の用途と「見本で試す」を最初の表示範囲に配置しました。
- 期間を選んで生活・仕事・治療の欄を補足できます。既存の欄変更処理と送信前確認を利用しています。
- 聞き返しは一つずつ表示し、受診・生活・仕事などは大きなラジオ選択肢で答えられます。空白は既存ルールが返した確認事項だけを「仮置き・未確認」と表示します。選んだだけで受診なしと確定することはありません。
- 保存して休む／再開に対応し、選択期間と確認中の位置も端末に保存します。保存失敗時には緑のチェックを表示しません。
- D1指定の単色、端末フォント、文字サイズ、300px以上の主入力欄、56px以上の操作部品を使用。390pxでは縦スクロール、1280pxでは3列で表示します。固定ボタンによる本文・キーボードの重なりはありません。

## 既存処理の保持

`src/core/`、`server/`、`api/`、`src/config/`、`src/client/`、既存単体試験、評価コード・正解データ、package/lockfile、Playwright設定を含む21ファイルが元の内容と完全一致しています。判定・日付計算・API・mock・呼び出し制限を変更していません。

既存の画面検証20件は、文言変更、閉じた設定の展開、一問ずつの質問への移動に必要な当て先・操作だけ調整しました。既存の期待値・検証意図は保持しています。追加の撮影と画面確認は `scripts/verify-design.mjs` に分離しました。
