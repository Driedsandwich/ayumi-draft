# 初めての人向けの導線修正 — あゆみの下書き

2026年11月6日。元の薄緑・白の配色、期間の一覧・入力カード・下書きの列構成を保って修正しました。

## 変更点

- 最上部に「①経過を書く（見本あり）→②期間と聞き返しに答える→③様式の順の下書きを見る」を配置。全段に現在地 `1 / 3` などを表示し、送信確認にも現在地を追加しました。
- 最も目立つ「見本で試す」は、見本の一覧へ移動するリンクから、架空の経過を入れるボタンに変更。直下に押した後の説明を添えました。別の見本は入力欄の下で選べます。
- 指定された料金の文を冒頭と実際の送信ボタンの近くに表示。ログイン不要、カード・支払い情報の入力欄がないことも明記しました。390pxでも冒頭のボタンと料金説明が最初の表示範囲に収まります。
- 「内容を確認して進む」で文を確認し、実際にAIを動かす操作は「AI で読む（数秒かかります）」と表示。見本は端末内の処理を選び、遅い接続通知が届いてもAIへ切り替わりません。自分の経過は「自分の経過を書く」からAIを選べます（接続済みの場合）。
- 最後の画面に「最初に戻る」「自分の入力で試す」を追加。前者は内容を保持し、後者は見本とその回答を空欄に戻します。見本を使わずに始めた入力は保持します。
- 「鍵なし」「解析」「コード」「JSON」、送信内容の内部項目名を、利用者向けの日本語に変更。「期間の帯」は「期間の一覧」、「仮置き」は「未確認の期間」としました。確認から戻る操作では元のボタンへフォーカスを戻します。
- `npmrc.legacy-peer-deps` を `.npmrc` に戻しました。中身は `legacy-peer-deps=true` の1行です。新しい依存はありません。
